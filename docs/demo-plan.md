# Demo Plan

## Goal

Prove that Body Controller is a configurable physical input system rather than a pose controller built for one specific game.

## Demo 1

Load the Runner profile.

Demonstrate:

- Lean left
- Lean right
- Jump
- Crouch

Show the physical movement and game response together.

## Profile Switch

Return to Body Controller.

Switch to a second profile.

Briefly show that gesture mappings changed.

## Demo 2

Launch a second keyboard-controlled game.

Perform several of the same physical movements.

Demonstrate that the active profile changes what those movements mean to the game.

## Message

The pose system determines what the player did.

The control profile determines what that movement means in the current game.
